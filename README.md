# 🧱 SwiftUI Demo

A beginner-friendly SwiftUI project covering the core building blocks of the framework — views, stacks, modifiers, and state — all in one runnable demo.

---

## 🤔 What this is

This project is a foundational SwiftUI demo that covers the essential concepts new developers need: `VStack`, `HStack`, `ZStack`, `Text`, `Image`, `Button`, `@State`, and common view modifiers. It's designed as a reference starting point when learning SwiftUI for the first time.

## ✅ Why you'd use it

- **Layout stacks** — `VStack`, `HStack`, `ZStack` side by side for comparison
- **@State** — simple counter and toggle examples showing reactive UI updates
- **View modifiers** — font, color, padding, background, cornerRadius in context
- **Button actions** — wiring user interaction to state changes

## 🚀 Getting Started

### 1. Clone the Repo
```bash
git clone https://github.com/NDCSwift/SwiftUIDemo.git
cd SwiftUIDemo
```

### 2. Open in Xcode
- Double-click `SwiftUIDemo.xcodeproj`

### 3. Set Your Development Team
In Xcode: **TARGET → Signing & Capabilities → Team**

### 4. Update the Bundle Identifier
Change `com.example.MyApp` to a unique identifier (e.g., `com.yourname.SwiftUIDemo`).

---

## 🛠️ Notes

- If you see a code signing error, check that Team and Bundle ID are set.

## 📦 Requirements

- iOS 16+
- Xcode 15+
- Swift 5.9+
